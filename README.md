## Summary
This project was developed during the summer semester of 2016 during my Bachelor's studies as a collaborative project with several other students. The goal was to combine exploration and small environmental puzzles with light-based gameplay mechanics.

## 🛠 Tech Stack
Unreal Engine, C++, Blueprint

## My Tasks
- Game Design
- Game Programming

### 🎮 Game Design
- Using a light source to scare away or attract different creatures
- Using the environment to the player's advantage, e.g. setting enemies on fire at fire pits
- Finding and using keys to unlock the next levels
